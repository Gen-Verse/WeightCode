Install new capabilities into trained networks by running a program.

A frozen language model reads a network's weights and the task knowledge, a rule, a few demonstrations or a few labeled examples, and writes an executable weight program. The program computes the new weights; the updated network runs on its own, and the program reruns on other networks.

01 · install

A rule, eight demonstrations or 64 images become a new capability.

The program writes the new computation into the network's existing weights. The network keeps what it could already do. Pick the kind of task knowledge:

Use a verb seen only alone, inside known commands

A Transformer trained on SCAN saw jump only on its own.

What the program wrote

It moves the embedding of jump to the centroid of walk, look and run, and adds an output row for its action. The composition the network already computes now carries the new verb.

known  jump → JUMP
before jump twice → ✗ wrong
after  jump twice → JUMP JUMP ✓

03 · open the network

The program writes a gate you can switch off and measure.

On the ViT-Lite under Gaussian noise, the program turns two idle MLP units into a ramp gate. It subtracts the measured noise shift only from tokens whose projection on a noise direction lies above the clean range.

04 · reuse and succession

Programs travel to new networks. Weight edits do not.

A program reads each network and writes that network's own edit, with no new LLM session. Later programs can build on an edited network without undoing it.

♻️ Rerun on five independently trained ViT-Lites

Clean accuracy stays within 1 pt on 48 of the 50 transfers. Rerun and copy: mean over the five networks, selection split. On ResNet-18s fine-tuned from the same ImageNet weights, a copied edit keeps 87–96% of the rerun gain: edits copy only between networks that share their starting point.

05 · use it today

Ask your coding agent. Get back a checked model and the program that built it.

The weightcode agent skill runs the whole workflow on your own model: import, bind your data, reuse or write a program in a sandbox, and release the update only if it holds up on data the program never saw. First supported model: torchvision ResNet-18.

claude · your-project

      

      

        
📥 You bring

          image sets (experience, selection, final) and the clean-accuracy loss you accept.

model.pt (updated only if accepted), the program
          bundle that reruns on other checkpoints, and report.json: accepted, base-kept or final-rejected.

The final split is scored once, after the choice is frozen.
          Edits are bounded and run in a bubblewrap sandbox with no network. Rerun on the same inputs, the program

06 · paper and data

    
Everything behind the numbers.

    

      
Abstract

      
Neural networks encode learned capabilities in their weights, yet extending those capabilities with explicit task knowledge remains a fundamental challenge. Here we show that executable weight programs can construct and install new computations directly within trained neural networks. WeightCode uses a frozen language model to write executable programs that translate task knowledge and measurements of a network’s weights and activations into weight modifications, selected by their effects on new and existing behavior; the installed computations run without the language model. Given a grammar or eight demonstrations, programs enable command compositions the network could not execute (exact match from 0% to 99.8%) and a new pickup action (success from 0% to 98.4%) while keeping the original commands and mission. On ImageNet, four programs improve a pretrained ResNet-18’s corruption robustness by 8.84–17.62 percentage points in net gain while preserving clean accuracy, exceeding the evaluated fine-tuning methods given the same task examples, external checks and retention rule. In a Vision Transformer, causal interventions show that an installed noise correction produces the robustness gain and that its selective activation protects clean accuracy. Rerun without the language model on five independently trained Vision Transformers, ten programs keep 83–110% of their source-network gains on average, whereas directly copying their numerical weight edits does not reproduce the gains. Programs written for an already edited network add a further capability while preserving the earlier gain. These findings establish executable weight programs as reusable specifications for constructing and extending capabilities within trained neural networks.
